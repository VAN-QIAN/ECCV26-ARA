### Tags

- Missing_Attribute_Constraint

### Definitions
1) Missing_Attribute_Constraint
The question refers to an attribute but does not specify which dimension or measurement is intended.
Example: "How big is this animal?" (size dimension unclear: length/height/diameter?)

2) Missing_Temporal_Scope
The question involves time-dependent facts but does not specify an exact period.
Example: "When is the mating period?" (month/season/lifecycle stage unclear)

3) Missing_Spatial_Reference
The question uses relative or vague spatial terms without defining a clear reference frame.
Example: "Where is this insect native?" (continent/country/county/city unclear)

### Fixing rules
- Use the annotated answer ONLY to make the question more specific; do not add facts not implied by the question+answer.
- If you cannot infer a safe, unambiguous fix, leave suggested_question empty.
- Keep the fix concise and directly aligned with the original intent.
