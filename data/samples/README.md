# Sample Inputs

Small one-row CSVs used by the runtime sample scripts.

- `evqa_fixed_1.csv`: first fixed E-VQA row, used by
  `scripts/run_echosight_evqa_reranker_sample.sh`.
- `infoseek_fixed_1.csv`: first fixed InfoSeek row, used by
  `scripts/run_iba_infoseek_sample.sh` and
  `scripts/run_wikiprf_infoseek_sample.sh`.
